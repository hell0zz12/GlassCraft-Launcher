# Changelog

Все заметные изменения GlassCraft документируются в этом файле.

## [0.2.0] - 2026-08-05

### Добавлено

- Сборка Windows portable/ZIP, macOS DMG/ZIP и Linux AppImage/deb через `electron-builder`.
- GitHub Actions для проверки, сборки трёх ОС и публикации артефактов по тегам `v*`.
- Автоматические тесты безопасной работы с путями, настройками, никами и внешними URL.
- Рабочие переключатели автоматического выбора памяти и Discord Rich Presence.
- Надёжные `start.bat`, `start-debug.bat` и `build.bat` с проверкой Node.js/npm и автоматическим `npm ci`.

### Исправлено

- Сохранённые аккаунты, серверы и игровое время теперь загружаются при старте.
- Игровое время записывается для реально запущенной версии, даже если выбор версии изменён во время игры.
- Кастомные версии корректно используют имя своей папки для запуска и управления.
- Удаление последнего активного аккаунта возвращает безопасный профиль `Steve`.
- Настройки Discord и памяти теперь действительно применяются при запуске.
- Ошибки запуска и инициализации больше не оставляют интерфейс в заблокированном состоянии.
- Метаданные репозитория, версия лендинга и документация синхронизированы с приложением.

### Безопасность

- Закрыт выход за игровую директорию при импорте версий, удалении контента и установке `.mrpack`.
- Добавлена нормализация профиля и настроек на границе Electron main process.
- Modrinth project/version повторно проверяются через API перед скачиванием.
- Скачивания ограничены по размеру и времени, проверяют HTTPS, редиректы и SHA-512/SHA-1.
- `.mrpack` читаются потоково с лимитами размера и количества файлов; конфликтующие и опасные пути отклоняются.
- Запись JSON-файлов сделана атомарной.
- Electron обновлён до `43.3.0`.

### Известные ограничения

- macOS-сборки пока не подписаны и не notarized.
- Оставшиеся npm audit-предупреждения приходят из неподдерживаемых зависимостей `minecraft-launcher-core`; планируется миграция launch engine.
