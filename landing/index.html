FAQ

Вопросы и ответы

Откуда берётся Minecraft?

Клиент, ассеты и библиотеки скачиваются с публичных CDN Mojang и Microsoft. Лаунчер ничего не хостит у себя.

Нужна ли лицензия?

Лаунчер запускает игру в offline-режиме. Использование клиента без лицензии — нарушение Minecraft EULA. Купить лицензию: minecraft.net.

Откуда берётся Java?

Из Eclipse Adoptium — это официальные сборки OpenJDK от Eclipse Foundation. Лаунчер сам определяет, какая Java нужна для выбранной версии MC, и скачивает её в свою папку.

Как работает Fabric?

Лаунчер запрашивает profile.json у meta.fabricmc.net, кладёт его в папку versions и передаёт MCLC. Никаких сторонних установщиков.

Где хранятся файлы?

По умолчанию — в ~/.glasscraft/. Игра, моды и Java лежат в подпапках. Путь к игре меняется в Настройках.

Это open source?

Да, MIT. Стек: Electron + Modrinth API + Fabric meta + minecraft-launcher-core.
